# Sushil Chaurasia · 3D Portfolio

Scroll-driven 3D portfolio built with Three.js. A gold pendant sits at the centre and the work hangs around it on a helix; the camera flies through each piece as you scroll.

- `index.html` is the whole site (artwork embedded), so it works as-is.
- `teaser.mp4` is the Armaan "1 Day To Go" teaser, played on its card.
- `assets/` holds the optimized artwork as separate files.
- `src-template.html` is the page source with a placeholder for the embedded artwork.

## Run
Open `index.html` in a browser, or serve the folder (`python3 -m http.server`). The video needs the two files side by side.

## Publish on GitHub Pages
Settings > Pages > Deploy from branch > `main` / root.
